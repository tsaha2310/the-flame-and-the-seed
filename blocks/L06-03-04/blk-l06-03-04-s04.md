The real code is arranged so that typos do the least harm. A change in a codon's third letter usually names the same bead. A change in the first or second usually names a bead of the same personality: oily for oily, polar for polar, from IV.5. The table is not random. It is laid out so that neighbouring codons name neighbouring beads.

A code with no spare words has no such cushion. Every typo is a bead change, and most bead changes are to something unlike. The same rate of slips gives several times the damage.

Copying the tape, in Book VIII, makes about one slip in a billion letters, which over a genome is a few per copy. Under the real code most of those are harmless. Under a strict code, most would not be. Redundancy is what makes imperfect copying survivable, and imperfect copying, in Book VIII, turns out to be needed.

**A code with no spare words turns most typos into broken proteins. The real code's redundancy, and its layout, make most typos harmless. That cushion is what lets the tape be copied at all.**
