> **The Lens says:** Fats drawn as a small head with three tails, at a hundred million times. Kinks are the real 30-degree bend of a double bond. Dispersion pulls are drawn as faint lines only when tails touch. Temperature is a dial as in the Crowd.

Set kinks to zero. Cool the box. Watch the tails line up. Read the melting point.

Set kinks to one. Cool. Watch what the kinked tails do to the packing. Read the melting point.

Set to three. Read.

Now, at room temperature, find the number of kinks at which the box changes from solid to liquid.
