Every element in a column has the same number of electrons in its outer shell.

- Lithium, sodium, potassium: one outer electron each. The fizzy metals.
- Fluorine, chlorine: seven outer electrons each. The greedy gases.
- Helium, neon, argon: a full outer shell. They join nothing. They do not even burn.

The electrons in the outermost shell are called valence electrons. They are the ones on the outside, furthest from the nucleus, highest on the Hill, and the only ones another atom can reach.

The table repeats because the shells fill up and start again. Every time a shell is full, the next element begins a new one with a single outer electron, and behaves like the last element that did.

**An element's family is set by how many electrons sit in its outer shell. Everything it does to other atoms is done with those.**

Mendeleev's mass order was a lucky stand-in for proton order, and proton order is really electron order, because a neutral atom has as many electrons as protons.
