> **The Lens says:** The nucleus is drawn a thousand times too big compared with the electrons' distance. Protons are red, neutrons grey, electrons blue; none of them has a colour. The electrons are drawn as dots in rings, which is a lie you will be told about tomorrow.

Start from nothing. Add one proton. Read the name.

Add electrons until the charge reads zero.

Add a second proton. Read the name again. Keep going up to twenty, adding electrons to balance.

Now go back to hydrogen and add a neutron. Then another. Read the name and the mass each time.

Then find out what happens to the name if you add or remove electrons instead.
