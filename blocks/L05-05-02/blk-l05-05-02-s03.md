The extender cannot start on nothing; it can only add a bead to an existing chain end. So a protein called glycogenin starts the account: it attaches the first few glucoses to itself and hands the short chain over.

The extender is glycogen synthase. It takes an activated glucose, one that has been tagged and then loaded onto a carrier nucleotide, paid for by coins, and joins it by an alpha link to the end of the chain, from IV.4's condensation. One bead, one join, one coin's worth.

The brancher is the branching enzyme. Every so often it snips a stretch of six or seven beads off a chain end and reattaches it to the side of the chain, by a different alpha link, making a fork. Now there are two ends where there was one.

A long unbranched chain has one end to add to. A branched tree has hundreds. Tomorrow's withdrawal needs those ends far more than today's deposit does.

**Glycogenin starts the chain. Glycogen synthase adds beads, a coin per bead. The branching enzyme cuts and reattaches, so the store is a tree with many ends.**

The store costs coins to build. It repays them with interest: each bead, when burned, recharges about thirty.
