> **The Lens says:** Rock layers with real fossil sequences; bones drawn from real skeletons; the code table from VI.3; DNA sequences from real genes, compared letter by letter. The Lens's deep-time trick is a dial that runs layers back millions of years.

Drawer one. Run the Lens down through rock layers. Note what appears in which layer and what never appears below a certain depth.

Drawer two. Lay a human arm, a bat wing, a whale flipper and a horse leg side by side. Count the bones. Match them.

Drawer three. Check the codon table for a bacterium, a moong plant, a yeast, a bee, a whale, and Kabir.

Drawer four. Compare one gene's letters between a human and a chimpanzee, a human and a mouse, a human and a moong, a human and a bacterium. Read the percent that match.
