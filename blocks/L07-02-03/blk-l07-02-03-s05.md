**Predict first:** what happens when a wave reaches the end of the cable?

**Turn the dial.** With no lockout, every spot can refire the moment its neighbour flips. A wave reaching any point sets off the point behind it as well. Waves run both ways, bounce off the ends, collide, and the cable rings like a struck bell, firing endlessly. The sim's muscle, downstream, seizes.

**What this nails:** The refractory period is what turns a chain of gates into a one-way path. Without it a nerve cannot carry a message; it can only ring.
