The name changes only when the number of protons changes. One proton is hydrogen. Six is carbon. Eight is oxygen. Eleven is sodium. Twenty-six is iron. The count of protons is the atomic number, and it says which element you have.

The nucleus also holds particles with no charge, called neutrons. They add mass and nothing else. A neutron weighs about the same as a proton. Electrons weigh almost nothing, about one two-thousandth of a proton.

So an atom's mass is nearly all protons plus neutrons. That total is called the mass number.

Add a neutron to hydrogen and it is still hydrogen. Just heavier. Atoms of the same element with different neutron counts are called isotopes. Ordinary hydrogen has no neutron. "Heavy hydrogen" has one. Ajji's heavy glass has a little of it.

**Protons decide what an atom is. Neutrons only decide how heavy it is.**
