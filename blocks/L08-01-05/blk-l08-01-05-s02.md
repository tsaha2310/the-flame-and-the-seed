> **The Lens says:** A population of a thousand simple organisms, each with a short genome, copying every generation; the environment is a set of conditions that shift now and then; fitness is judged by the sim's rules, which stand in for the real world. Generations pass in seconds.

Set the rate to zero. Run. Watch the population through the first shift.

Set one in a thousand. Run. Watch the population before any shift.

Set one in a million. Run. Then one in a billion, scaled to the sim's short genome. Watch each through three shifts.

Find the range of rates in which the population lives through all three.
