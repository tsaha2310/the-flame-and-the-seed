Splicing must be exact because the ribosome reads in threes with no markers. A join one letter off is a deletion or an insertion, and the frame is lost. Real splicing machines get it right almost every time, and the boundary signs are what let them.

Bacteria skip all of it. No envelope, no introns, no splicing, no cap, no tail. The copyist writes and the ribosomes read the same strand at the same moment, and a protein can be made within a minute of the gene being switched on. That speed is why bacteria can double every twenty minutes.

A plant or animal cell pays several minutes per message for the nucleus, and buys protection for the tape, a room to edit in, alternative splicing, and a set of control points, on the pores and on the chromatin, that a bacterium does not have. VI.6 uses them.

**Splicing one letter off is a frameshift, so it must be exact. Bacteria, with no nucleus, read a message while it is being written and are fast. Eukaryotes edit first, and are slower and more controllable.**
